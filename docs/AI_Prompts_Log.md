# AI 协作记录（AI_Prompts_Log）

> 负责人：叶世航（汇总）｜ 各条目由实际执行人填写并核对

本文件记录本项目在开发过程中使用 AI 工具的真实过程。每条包含：做什么、给 AI 的原始指令、AI 输出的问题、我们怎么改。**AI 出错的部分同样保留**，因为它能说明哪些判断是我们自己做的。

## 一、代码结构重构（执行人：袁恒宇）

**背景**：最初所有代码写在一个 1400 行的 `K-means.py` 里，界面、算法、动画、导出混在一起，四个人同时改会互相覆盖。

**原始指令**：

> 把这个 1400 行的单文件按四个人分工拆成模块，要求界面和算法分离，算法层不依赖 Tkinter，并且每一步都要能单独测试。

**AI 输出**：一个 `kmeans_lab/` 包，按 config / data / initialization / metrics / algorithm / view / ui / animation / export / app / main 划分，并给出各模块之间允许调用的接口。

**采纳**：整体包结构与接口划分；`view` 只接受 `Scene` 数据快照（这样动画补间可以把插值后的质心直接传进去）；`app` 作为唯一的胶水层。

**AI 的问题**：

1. 最初把 SSE 计算同时写在 `algorithm.py` 和 `metrics.py` 里，两份实现会随时间漂移 → 我们统一成 `metrics.inertia()`，`algorithm.py` 只调用；
2. 最初让 `view.py` 直接读 `app` 的属性取数据，导致绘制层与控制器耦合、无法脱离界面测试 → 改成传入 `Scene` 快照。

**结论**：结构可用，但"谁负责算指标"这一条必须人工定死，AI 会为了局部方便而重复实现。

## 二、单元测试（执行人：袁恒宇）

**原始指令**：

> 给这套算法补单元测试，覆盖数据生成、初始化、迭代收敛、指标计算、导出。

**AI 输出**：7 个测试函数，覆盖收敛性、质心等于簇内均值、非法 K 报错、重复点等边界。

**采纳**：全部保留，并扩展到 21 项（增加初始化可复现性、轮廓系数边界、K 值推荐、CSV 往返读写、置信椭圆几何）。

**AI 的问题**：

1. 断言"只有一个簇时轮廓系数为 0"——按定义此时无法计算，应为 `None`，实现和断言都改了；
2. 没有覆盖"空簇"分支：测试数据里每个簇都有样本，测不到"某质心没分到点"的处理逻辑 → 补充全重复点的极端用例；
3. 有一个测试直接 import Tkinter 控件，导致无图形环境就跑不起来 → 改为只测纯函数。

**结论**：AI 能写出"能过"的测试，但不一定测到难走的分支；边界在哪里仍需人来判断。

## 三、文档与代码一致性核查（执行人：袁恒宇）

**原始指令**：

> 逐条核对 README 里的功能描述和代码实际行为，列出不一致的地方。

**AI 发现并修正的错误（原 README 有误）**：

| 文档原文 | 实际代码 |
|---|---|
| 聚类数 K 支持 2–6 | `MIN_K=2, MAX_K=8`，实为 2–8 |
| 可显示点到质心的归属连线 | 程序没有该功能 |
| 按钮名为"单步执行""自动播放""生成数据" | 实为"单步迭代""连续运行 / 暂停""生成数据 / 应用设置" |
| 依赖"仅需自带 tkinter，无需 pip 安装" | 必须 `pip install numpy matplotlib`，否则起不来 |
| 只列了 5 项功能 | 漏掉手动放置质心、K 值分析、置信椭圆、CSV 与图像导出 |

**结论**：这类"文档写了、代码没有"的问题通读很难发现，逐条比对效率很高，但**每条结论都要回代码确认**（AI 也曾把图例位置当成功能误报）。

## 四、合并冲突解决（执行人：袁恒宇）

**背景**：`feature/ui` 与 `feature/core` 两条分支都修改了侧栏宽度和 README 中同一句功能说明，合并时 Git 报两处冲突。

**原始指令**：

> 这两处冲突，双方改动都合理，给我一个裁决建议。

**AI 输出**：`SIDEBAR_WIDTH` 建议取中间值 300（312 是为避免控件文字换行，288 是为适配 1024 宽屏）；README 保留信息更完整的一版措辞。

**人工处理**：接受建议，在常量上方补一行注释说明取值依据；删掉 `<<<<<<< / ======= / >>>>>>>` 标记后跑 `python K-means.py --self-test`（21 项）确认无回归，再提交合并。

**结论**：AI 能给"折中值"，但**折中的理由必须写进代码**，否则下次还会被改回去。

## 五、文档配图生成（执行人：袁恒宇）

**原始指令**：

> 手册里的截图位置要换成真实运行结果，而且要能复现，不要手截图。

**AI 输出**：把 `show_k_analysis()` 里绘图部分拆成不依赖 Tk 的 `build_k_analysis_figure()`，再写 `tools/generate_figures.py`，用项目自身的 `data` / `algorithm` / `view` 模块跑出 7 张图存进 `images/`。

**采纳**：`view.build_k_analysis_figure()` + `tools/generate_figures.py`，图与运行结果完全一致，重跑脚本即可更新。

**AI 的问题**：第一版脚本用相对当前工作目录的路径，换个目录运行就找不到输出位置 → 改为基于 `Path(__file__).resolve().parent.parent` 定位项目根目录。
