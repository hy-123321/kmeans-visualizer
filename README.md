\# K-Means 聚类算法迭代过程可视化



一个基于 Python + Tkinter 的桌面演示程序，动态展示 K-Means 聚类算法的完整迭代过程。



\## 项目简介



K-Means 是经典的\*\*无监督学习\*\*聚类算法。本项目通过可视化方式，逐步展示：



\- 数据点的生成

\- 质心的初始化

\- 簇的分配过程

\- 质心的更新

\- 算法的收敛判断



帮助学习者直观理解 K-Means 的工作原理。



\## 功能特性



\- 随机生成二维数据点

\- 可设置聚类数 K（2–6）

\- 支持单步执行与自动播放

\- 实时可视化散点、簇着色、质心位置

\- 统计迭代轮数、SSE 等指标

\- 支持速度调节



\## 运行环境



\- Python 3.8 及以上

\- Tkinter（Python 自带）
